# References and implementation choices

| Reference | Decision |
|---|---|
| [SaaSfly](https://github.com/nextify-limited/saasfly) and [Create T3 App](https://create.t3.gg/) | Useful examples of typed full-stack boundaries. Seatsplice keeps a small React and Express project aligned with PS1's suggested stack. |
| [Bento Starter](https://github.com/kefranabg/bento-starter) | The matching public project uses Vue and Firebase. |
| [MERN Starter](https://github.com/joshuaslate/mern-starter) | Close stack match, but its README points users toward a newer Koa starter. Seatsplice uses a current dependency lockfile. |
| [Twenty](https://github.com/twentyhq/twenty), [Strapi](https://github.com/strapi/strapi), and [Real World React Apps](https://github.com/jeromedalbert/real-world-react-apps) | References for navigation, application structure, and real projects. The event app has a narrower domain and its own source. |
| [Linear](https://linear.app/), [Radix Skeleton](https://www.radix-ui.com/themes/docs/components/skeleton), and [shadcn Skeleton](https://ui.shadcn.com/docs/components/base/skeleton) | Informed the compact workspace navigation and loading placeholders that hold the shape of the finished content. |
| [21st](https://21st.dev/), [Hover.dev](https://www.hover.dev/), [Animate UI](https://animate-ui.com/), and [Motion](https://motion.dev/docs/react) | Reviewed for button and state feedback. The interactions are implemented in CSS, with reduced-motion support. |
| [Motion’s Coverflow](https://motion.dev/examples/react-gallery-coverflow), [Cards](https://motion.dev/examples/react-gallery-cards), and [Ice lollies](https://motion.dev/examples/react-gallery-ice-lollies) | Visual references for the team picker. Seatsplice uses original SVG illustrations, a keyboard- and swipe-controlled deck, and a list view for scanning. |
| [Motion AI Kit](https://motion.dev/ai-kit) | The particle scene inspired the sign-in artwork. Seatsplice renders a short original 2D scene that stays still with reduced motion and never delays the form. The Motion CLI was explored separately from the project; the app does not require a Motion+ key. |
| [Motion examples](https://motion.dev/examples?plus=true) | Copy confirmation, a brief blinds reveal, and a one-time scramble welcome communicate changes in place. The create action stays labeled, and notifications use one status region. Confetti, a floating button, and an extra sheet would compete with the main action or repeat an existing screen. |
| [Animata](https://animata.design/), [shadcn buttons](https://www.shadcn.io/button), [GSAP](https://gsap.com/), [React Spring](https://react-spring.dev/), [Lottie](https://lottiefiles.com/), and [Rive](https://rive.app/) | Useful reference points for short feedback and richer animation. CSS and Canvas cover this app’s small motion vocabulary without an animation runtime or downloadable assets. |
| [Logo Design skill](https://github.com/kaankiziltug/logo-design-skill) | Used the principle of checking a simple vector at icon size. The two interlocking seat brackets are original and use the same mark in the rail, login and favicon. |

Claude Code installed three project-scoped skills in `.claude/skills`: MongoDB Schema Design, MongoDB Query Optimizer, and Grafana k6. The installation recorded upstream commits and file hashes. These development aids are outside the application runtime and are excluded from the submission repository.
